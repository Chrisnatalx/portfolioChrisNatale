my own project · second brain

AlterNata

My second brain on Discord. When someone mentions me, it answers in my voice with a memory that stays up to date. If someone asks for a change to a project, it implements it, but push, merge and deploy wait for my approval by message.

where the AI isA Claude Code session connected to Discord through Channels. It works as a dispatcher: it sorts each request and hands the heavy work to subagents in worktrees. It only sees the projects folder on my PC, its memory is markdown versioned in git, and it treats any instruction inside a message, PR or file as data, not as an order.
